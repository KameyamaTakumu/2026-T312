# 惑星探訪記

## 概要

**惑星探訪記** は、惑星ごとに異なる重力が働く3Dアクションゲームです。

プレイヤーは3つの惑星を探索し、惑星の表面を自由に移動しながら、ジャンプやスピンアクション、コイン投擲などを駆使してステージを攻略します。

惑星間の移動や特殊な重力を利用した小惑星渡り、動く床などのギミックを攻略しながら進み、最後の惑星に待ち受けるボスの撃破を目指します。

「重力」「惑星移動」「スピンアクション」「コイン投擲」などを組み合わせた、惑星探索型の3Dアクションゲームです。

# ゲームの特徴

* 惑星の表面を自由に移動できる特殊な重力システム
* 3つの惑星を探索するステージ構成
* 惑星間を移動するギミック
* 動く床などのステージギミック
* スピンによる近距離攻撃
* マウスカーソルを利用したコイン回収
* 回収したコインを利用した遠距離攻撃
* 追いかけてくる敵と逃げる敵の2種類の敵AI
* 条件に応じて発生するステージイベント
* 操作ごとに実際に体験しながら学べるチュートリアル
* 最終惑星にボスが登場

# プレイヤー操作

| 操作                       | 内容       |
| ------------------------ | -------- |
| W                        | 前方へ移動    |
| S                        | 後方へ移動    |
| A                        | カメラを左へ移動 |
| D                        | カメラを右へ移動 |
| Space                    | ジャンプ     |
| Left Shift / Right Shift | スピン      |
| マウスカーソル                  | コイン回収    |

### 移動

プレイヤーは惑星の表面を自由に移動できます。

惑星ごとに重力の方向が設定されており、通常の地面だけでなく、球体惑星の側面や裏側でも重力に沿って移動できます。

移動操作は**W・Sによる前後移動**を基本とし、**A・Dでカメラを左右に操作**します。

また、プレイスタイルに合わせて**カメラの向きを反転できる機能**も搭載しています。

### ジャンプ

Spaceキーでジャンプします。

ジャンプ中も惑星ごとの重力方向が適用されるため、球体惑星の形状に合わせた立体的な移動が可能です。

---

# スピンアクション

Left ShiftまたはRight Shiftでスピンを使用できます。

プレイヤーの周囲に攻撃判定が発生し、近くの敵やギミックに対して使用できます。

### スピンの用途

* 敵への攻撃
* スピンスイッチの起動
* ステージギミックの操作

スピンは単純な攻撃だけではなく、ステージ攻略にも使用する重要なアクションとして設計しています。

---

# コインシステム

ステージ各地にコインが配置されています。

## コイン回収

マウスカーソルをコインに合わせることでコインを回収できます。

プレイヤーが直接コインに接触する必要がなく、カーソルを利用して離れた場所のコインを回収できるシステムになっています。

## コイン投擲

回収したコインを消費して、敵へ向けて投擲することができます。

### 特徴

* マウスポインターの方向へ発射
* 敵に命中するとダメージを与える
* 遠距離から敵を攻撃できる
* 敵によってコイン攻撃への反応が異なる

---

# 敵システム

敵には複数の行動パターンを用意しています。

## 追跡型の敵

プレイヤーが一定範囲内に入ると、プレイヤーを追いかけてきます。

範囲外へ移動すると追跡を終了します。

### 攻撃方法

* 踏みつけ
* コイン投擲

追跡型の敵はコインを命中させることでダメージを与えることができます。

---

## 逃走型の敵

プレイヤーが近づくと、プレイヤーから逃げる敵です。

追いかける敵とは異なる立ち回りが必要となり、プレイヤーとの距離を維持しながら逃走します。

逃走型の敵はコインを当ててもダメージを受けず、コインによる攻撃が通用しない敵として設計しています。

---

## 踏みつけ

敵の上方向から接触することで踏みつけ攻撃を行えます。

踏みつけに成功すると敵へダメージを与え、敵によっては撃破することができます。

また、**踏みつけが通用しない敵**も存在します。

敵ごとに有効な攻撃方法を変えることで、敵の特徴を考えながら攻略する必要があります。

### 敵ごとの特徴

| 敵タイプ | 行動        | 踏みつけ     | コイン      |
| ---- | --------- | -------- | -------- |
| 追跡型  | プレイヤーを追跡  | 敵によって異なる | 有効       |
| 逃走型  | プレイヤーから逃走 | 敵によって異なる | 無効       |
| 特殊型  | 個別の行動     | 無効の場合あり  | 敵によって異なる |

---

# スピンスイッチシステム

ステージにはスピンで起動できるスイッチが配置されています。

### 特徴

* スピン範囲内に入ると起動
* 一度起動すると解除不可
* スイッチをグループ化可能
* グループ内の全スイッチを起動するとイベント発生

### 発生可能なイベント

* 扉を開く
* オブジェクトを生成
* 足場を出現させる
* 惑星を出現させる
* コインを出現させる
* ステージギミックを起動する

イベントはInspectorから設定できるため、同じスイッチシステムを利用して様々なステージギミックを構築できます。

---

# ステージギミック

ステージには、プレイヤーの移動やアクションを利用して攻略する様々なギミックを配置しています。

## 動く床

一定の範囲を移動する床です。

プレイヤーは動く床に乗りながら次の足場へ移動する必要があり、タイミングを考えたジャンプや移動が求められます。

## 重力ゾーン

重力ゾーン内では通常とは異なる重力が発生します。

### 挙動

1. プレイヤーが重力ゾーンへ侵入
2. ジャンプを行う
3. 指定された重力方向へ引き寄せられる
4. 別の惑星や小惑星へ移動する

これにより、

* 惑星間移動
* 小惑星渡り
* 空中ルート探索

などの特殊な移動が可能になります。

---

# 惑星移動システム

ゲームには**3つの惑星**が存在します。

惑星ごとに異なるステージを用意し、探索を進めながら次の惑星へ移動していきます。

## 大惑星移動

大きな惑星へ移動する際には、

* フェード演出
* シームレスな遷移

などを利用して惑星間の移動を演出します。

## 小惑星移動

小惑星への移動では重力ゾーンを利用します。

通常の足場とは異なる方向へプレイヤーを引き寄せることで、惑星から惑星へ飛び移るような特殊な移動を実現しています。

## 最終惑星

3つ目の惑星には**ボス**が存在します。

各惑星を攻略して最終惑星へ到達し、最後に待ち受けるボスを撃破することがゲームの大きな目標となります。

# イベントシステム

ステージ上では、特定の条件を満たすことでイベントを発生させることができます。

### イベント例

* 惑星の出現
* コインの出現
* 扉の開閉
* 足場の出現
* オブジェクトの生成
* ステージギミックの起動

イベント内容をInspectorから設定できるため、プログラムを変更せずにステージごとの演出や仕掛けを構築できます。

---

# チュートリアルシステム

ゲーム開始時に操作方法を一方的に説明するのではなく、**実際にプレイヤーが操作しながら覚えられるチュートリアルシステム**を実装しています。

### 体験できるチュートリアル

* 移動
* ジャンプ
* スピン
* コイン回収
* コイン投擲

プレイヤーがそれぞれの操作を実際に行うことで、段階的にゲームシステムを理解できる構成になっています。

チュートリアルデータにはScriptableObjectを使用しています。

### 設定可能項目

* 表示テキスト
* 表示時間
* 表示オブジェクト
* オブジェクト表示位置
* 表示順

Inspector上から内容を編集できるため、プログラムを変更せずにチュートリアルの構成を変更できます。

## Inspectorアニメーター

Unity標準Animatorとは別に、Inspector上からアニメーションを設定できるシステムを実装しています。

### 機能

* アニメーション登録
* 遷移条件設定
* ステート切り替え
* パラメータ管理

コードを直接編集せず、Inspector上からアニメーションの設定を行えるようにしています。

---

## Inspector表示改善

Unity Inspectorの変数名を日本語表示できる仕組みを実装しています。

### メリット

* Inspectorの視認性向上
* 設定項目を把握しやすい
* 設定ミスの削減
* Unity初心者でも扱いやすいInspectorを構築

---

## サウンド管理システム

BGMやSEを一元管理するためのサウンド管理システムを実装しています。

### 機能

* BGM再生
* BGM停止
* SE再生
* Enumによる音源指定

Enumを利用することで、音源名を直接文字列で入力する必要をなくし、タイピングミスを防止しています。

---

## シーン管理システム

シーン遷移処理を簡略化するためのシーン管理システムを実装しています。

### 機能

* シーンロード
* シーン切り替え
* フェード演出との連携

シーン名を直接記述する必要を減らし、シーン遷移処理の保守性を高めています。
