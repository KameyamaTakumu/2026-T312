# MarioGalaxy（仮）

## 概要

**MarioGalaxy（仮）** は、惑星ごとに異なる重力が働く3Dアクションゲームです。

プレイヤーは球体惑星の表面を自由に移動しながら、スピンアクションやジャンプを駆使して敵を倒し、コインを集めながらステージ攻略を目指します。

「重力」「惑星移動」「スピンアクション」など、ギャラクシー系アクションゲームの要素を取り入れた作品です。

# ゲームシステム

## プレイヤー操作

| 操作         | 内容     |
| ---------- | ------ |
| WASD       | 移動     |
| Space      | ジャンプ   |
| Left Shift | スピン（仮） |
| マウス左クリック   | コイン投擲  |

### 移動

* プレイヤーは惑星表面を自由に移動可能
* カメラはプレイヤーを追従
* 見下ろし視点でプレイ

### ジャンプ

* スペースキーでジャンプ
* 惑星ごとの重力方向に合わせて移動

### スピンアクション

* プレイヤー周囲に広めの判定を持つ攻撃
* スピンスイッチの起動が可能
* ギミック解除に利用

---

## スピンスイッチシステム

ステージにはスピンで起動できるスイッチが配置されています。

### 特徴

* スピン範囲内に入ると起動
* 一度起動すると解除不可
* スイッチはグループ化可能
* グループ内の全スイッチ起動時にイベント発生

### 発生可能なイベント例

* 扉を開く
* オブジェクト生成
* 足場出現
* ステージギミック起動

など、Inspector上で自由に設定可能です。

---

## 敵システム

### 敵AI

* 一定範囲内に入るとプレイヤーを追跡
* 範囲外に出ると追跡終了

### 踏みつけ

プレイヤーが敵の上から接触すると敵を倒せます。

#### 設定可能項目

* 踏みつけ判定範囲
* 跳ね返り力
* ダメージ量
* 撃破時処理

---

## コインシステム

ステージ各地にコインを配置。

### コイン取得

* 接触で回収

### コイン投擲

回収済みコインを消費して攻撃可能。

#### 操作

* マウス左クリック

#### 特徴

* マウスポインター方向へ発射
* 敵へ命中するとダメージ
* 遠距離攻撃として活用可能

---

## 惑星移動システム

### 大惑星移動

大きな惑星へ移動する際は、

* フェード演出
* シームレスな遷移

を行います。

### 小惑星移動

重力ゾーンを利用して移動します。

---

## 重力ゾーン

重力ゾーン内では特殊な重力が発生します。

### 挙動

1. プレイヤーが重力ゾーンへ侵入
2. ジャンプを行う
3. 指定された重力方向へ引き寄せられる

これにより、

* 惑星間移動
* 小惑星渡り
* 空中ルート探索

が可能になります。
