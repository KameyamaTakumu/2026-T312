タイトル：MarioGalaxy（仮）
開発環境：Unity
使用言語：C＃
どんな人向け：アクションゲームが好きな人・マリオギャラクシーが好きな人
ジャンル：3D惑星アクションゲーム
キーワード：マリオ・アクション・重力

ゲームの中身：
プレイヤーはWASDで移動できる。
移動にカメラはついてくる。
左シフト（仮ボタン）でスピンが行える。
スピンの範囲はプレイヤーよりは広い。
スピンを行ったときに作動するスイッチが存在している。
そのスイッチはグループ化されている。
そのグループすべてのスイッチが起動すると、何かの処理（設定可能）が走る。
スピンを行ったとき、周囲にスピンスイッチがあった場合スイッチが起動する。
スイッチは一度起動状態にするとオフにすることはできない。
スペースでジャンプができる。
プレイヤーを見下ろす感じのカメラ。
一定範囲内にプレイヤーが入ってきたら追いかける敵を配置。
範囲外から出た場合には追いかけるのをやめる。
プレイヤーが上から踏みつけると敵を倒すことができる。
踏みつけの設定なども細かに設定可能にする。
各地にコインを設置。
コインは取得することができる。
コインを取得した状態で、マウスの左ボタンを押すと、そのマウスポインターにコインを飛ばす。
コインを投げたときに、敵に当たると敵にダメージを与えられる。
大惑星の移動時には、フェードが入る。
小惑星の移動時は重力ゾーンを渡って移動する。
重力ゾーンはその範囲内に入っている状態でプレイヤーがジャンプをすると、その重力に引っ張られる。

プログラム面：
チュートリアルの中身をScritableObjectで設定でき、順番も自由に設定可能。
中身：表示する文字、Run時の指定秒数、表示するオブジェクト、オブジェクトの位置
アニメーションをインスペクター内で設定できる。
遷移条件などを設定可能。
インスペクター版アニメーター。
インスペクター内の変数を日本語にして視認性を向上させる。
サウンド（BGM,SE）を簡単に設定・呼び出し可能にし負担を減らす。
シーン遷移などを簡単にする。
